# Docs Index

Documentation is the main artifact of this project's current phase. Keep this
index updated whenever a doc is added, renamed, or retired.

## Core

| Doc | Purpose | Cadence |
|-----|---------|---------|
| [PLAN.md](PLAN.md) | Vision, goals, scope, roadmap | Update when scope/priorities change |
| [PROGRESS.md](PROGRESS.md) | Session log — what was done, what's next | Every session, newest first |

## Decision records

[decisions/](decisions/README.md) — numbered ADRs for hard-to-reverse choices.
Template: [0000-template.md](decisions/0000-template.md).

## Notes

[notes/](notes/README.md) — loose research, ideas, open questions. Free-form;
promote anything durable into PLAN.md or an ADR.

## Conventions

- Markdown, one topic per file, filenames in `kebab-case.md`.
- Every doc starts with a one-line "what is this" so it's self-identifying.
- Dates are ISO (`YYYY-MM-DD`).
