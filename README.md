# mars_colony
A small spaceship with 4 brave astronauts landed on Mars. The last few weeks they spent on setting up their habitat for long term habitation. A disaster occurs, and their spaceship cannot return to earth anymore. With their resources declining, how will they survive?

In this project, I propose the students build a simulation that represents the Martian habitat,
in which 4 Agents can walk around and do things. These Agents (the astronauts) are
controlled by an LLM. The Agents can walk around, do things in the spaceship to keep their
health up (eat, exercise, drink, go the toilet, sleep) and crucially: Talk to each other. Each
Agent (instance of an LLM) has its own long term memory, personality and goals. Their goal
is to survive and ideally let all four of them survive. But if resources are low, and one of the
agents has a broken leg, how will the agents behave?

(optional bonus feature): The Agents can also contact mission control for guidance. This
mission control will be played by humans, who can either use a text or a voice interface to
intervene in the situation, and give the Agents suggestions on how to proceed.

The outcome of the project should be a working simulation, that uses LLM to drive the
agents (astronauts) through the simulation. The challenges will be on the one hand
designing the simulation (but Agentic Programming can help with that), and secondly,
designing the Agentic loop so that each Agent can function and think similar to a human
actor, using long term memory, goals and actions.
This Platform can be used for various interesting research topics. We could use it to
investigate:
- How do different system prompts change the behaviour of the Agents
- How do different LLMs deal with this scenario? Which LLM has the highest survival
rate?
- How does human intervention impact the simulation?
The complexity of the simulation, and many of the details such as time lines and time steps,
what actions the agents can take etc. can be designed by the students. For simplicity, it can
also be turned into a simulation of two individuals stranded on a remote island, but I like the
mars idea better. Agentic Programming can be used to build this application, Thomas is also
available to support with implementation details.
